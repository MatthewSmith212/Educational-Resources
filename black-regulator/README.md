# The Black Regulator

A self-contained web page explaining Roman Black's two-transistor self-oscillating buck regulator
(original: https://www.romanblack.com/smps.htm): the mechanism first, then an extensive Q&A,
a worked design example, a glossary and an in-browser behavioural simulator.

Open `index.html` in a browser. `sim.js` is the simulator; `img/` holds the original drawings and scope photos.
Component values on the page are representative, chosen for illustration; the original drawings print none.
